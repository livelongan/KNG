# 章回体文体指南(红楼梦式 · 架空宋制)

## 一、章回体框架

- 回目:两句对仗,各 7–9 字,词性结构与节奏相对(不严究平仄,但须上口),如「闻圣眷初膺郡守 议漕粮众论动京华」。回目一律取自 summary 回目对照表,行文时不自拟。
- 回内结构:回目 →(回前诗,可选)→「话说」承上回 → 正文 →「正是:<两句>」→「毕竟不知后事如何,且听下回分解」。
- 转场套语:却说 / 且说 / 话说 / 当下 / 次日 / 一宿无话 / 不在话下 / 按下不表;预叙用「有分教」;「看官听说」偶用点题。
- 文件名与原稿一致,回目写在文件首行;`.txt` 源不使用 markdown 标记。

## 二、世情笔法

- 以家宅、官署、书院、市井的日常写人情:宴饮、诗会、拜会、通帖、送礼、求情、参劾是标准场景形态。
- 白描:动作、神态、服饰器物见身份地位;不写大段心理独白,情绪从言行与他人反应透出。
- 对话短促有性情;门子、长随、丫鬟、嬷嬷等配角一两句闲笔见世态。
- 每回开头 200 字内接前文入新场景;回末钩子 = 新变故或悬念一句。

## 三、架空宋制(世界观骨架)

- 官制仿宋(元丰改制后):中枢 = 政事堂(同平章事、参知政事)+ 枢密院 + 六部(尚书/侍郎/郎中/员外郎);地方 = 路—州府—县:知州/通判/签判/知县/县丞/主簿;监察 = 御史台、提点刑狱司;财赋漕运 = 转运司。
- 科举:州试 → 省试 → 殿试,进士分五甲;座师/房师/同年是重要人脉线。
- 品级九品十八级,文尊武卑;寄禄官表阶、差遣表职,称谓带差遣(如「知临澜府事」)。
- **架空红线**:年号自拟(承平、景和等,全书一致);今上不书名;不出现真实历史人物(可虚写「三苏遗风」「旧党元老」式影子,不给真名);都城州府地名自拟雅名(云京、临澜府、望江州)。
- 官署名优先用宋制实名(枢密院、国子监);需要新机构时仿宋式造名(如「厘务司」)并**先补入映射总表**。

## 四、称谓(全篇统一,新增先入映射表)

- 官场:大人 / 宪台 / 部堂;自称 下官 / 学生 / 晚生;同寅称 兄台 / 世兄;门生称 座师 / 房师。
- 家宅:老爷 / 太太 / 夫人 / 姑娘 / 小姐 / 哥儿 / 姨娘;仆从:门子 / 长随 / 管家 / 嬷嬷 / 丫鬟。
- 士人互称:兄 / 足下 / 仁兄;书信抬头具礼数。

## 五、名物

- 器物:汝窑定窑、蜀锦杭缎、点茶茶筅、焚香汝炉、瓦舍勾栏、漕船、书院书局。
- 度量衡:里 / 丈 / 尺 / 贯 / 缗 / 两 / 石;时间:时辰 / 更 / 旬 / 朔望 / 年号纪年。
- 货币可设「交子」类纸币但须架空改名(如「通行宝券」),入映射表;宴席按宋俗一两笔带过,不堆砌。

## 六、诗词韵文

- 必备:回目对仗、回末「正是」两句;常备:回前诗或回中诗词 1–3 处(宴集可联句、行酒令、制灯谜)。
- 诗以五七言绝律为主,词牌选常见(西江月 / 临江仙 / 鹧鸪天);**诗必须贴合当下情境与人物心绪**,严禁空话堆砌。
- 原稿金句可化用为诗联;重要人物出场可制判词式预叙。

## 七、语言禁忌

- 现代词零容忍:公司 / 电话 / 心理 / 效率 / 逻辑 / 秒 / 公里 / 公斤等;遇到先查映射总表,表外先补表。
- 欧化长句拆短;不用翻译腔;虚词可用之乎者也,但整体文白相间,以今人能顺读为度(红楼梦语感,不作全文文言)。
- 原稿残留检查:写作中每回至少自查一次是否漏映射(机构名、器物名、称谓)。

## 八、与原稿的边界

- 情节走向、章节边界、伏笔回收位置不变;每回篇幅 80%–120%。
- 连续 12 字雷同禁(公共章回套语豁免);人物姓氏全部古雅化(名 + 表字入人物表)。
- 查重脚本的命中若为公共套语(话说/却说/且听下回分解等),可在汇报中标注豁免;其余必须改写。
