# 术语表(translate-zh)

翻译时必须遵循本表;新术语译完后追加到「追加区」,保证整批一致。

## 通用规则

- 中文与英文/数字之间留一个空格,如「使用 Vite 构建」「共 13 个模型」。
- 使用全角标点(,。:;?!「」),代码与命令内部保持半角。
- 专有名词、代码、命令、文件路径、API 名称一律不译。
