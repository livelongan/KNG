# 章回体文体指南(红楼梦式 · 架空明兴)

## 一、章回体框架

- 回目:两句对仗,各 7–9 字,词性结构与节奏相对,如「议开海廷争动朝纲 查盐引银潮涌别府」。回目一律取自 summary 回目对照表,行文时不自拟。
- 回内结构:回目 →(回前诗,可选)→「话说」承上回 → 正文 →「正是:<两句>」→「毕竟不知后事如何,且听下回分解」。
- 转场套语:却说 / 且说 / 话说 / 当下 / 次日 / 一宿无话 / 不在话下 / 按下不表;预叙用「有分教」;「看官听说」偶用点题。
- 文件名与原稿一致,回目写在文件首行;`.txt` 源不使用 markdown 标记。

## 二、世情笔法

- 场景形态:衙署议政、内阁票拟、司礼监批红、科道风闻、书院讲会、盐商宴集、织坊瓷窑、市井坊铺、家宅内闱。
- 白描:动作、神态、服饰器物见身份;不写大段心理独白,情绪从言行与他人反应透出。
- 对话短促有性情;门子、长随、管家、嬷嬷、小内侍等配角一两句闲笔见世态。
- 每回开头 200 字内接前文入新场景;回末钩子 = 新变故或悬念一句。

## 三、架空明制(政治骨架)

- **架空红线**:年号自拟(全书一致);今上不书名;不出现真实历史人物;都城州府地名自拟雅名;新机构仿明式造名(如「厘正司」)并**先补入映射总表**。
- 中枢:内阁(首辅 / 次辅 / 群辅,票拟)+ 司礼监(掌印太监 / 秉笔太监,批红)—— **票拟与批红之争是政斗核心引擎**。
- 六部:吏户礼兵刑工(尚书 / 侍郎 / 郎中 / 员外郎 / 主事);都察院左都御史、六科给事中、十三道监察御史(科道风闻奏事)。
- 厂卫:锦衣卫与东厂(可架空改名:缇骑 / 内缉厂),缉捕诏狱,权势熏天亦招怨。
- 地方:布政使司 / 按察使司 / 都指挥使司三司 → 知府 / 同知 / 通判 → 知县 / 县丞;巡抚、总督为差遣。
- 军事:卫所、总兵官;科举:童试 → 乡试(举人)→ 会试 → 殿试;八股时文;翰林院庶吉士为清贵之路;捐纳监生。

## 四、中兴经济(经济骨架,本技能重点)

- 货币:白银为主(纹银 / 足色 / 银两计价),宝钞渐废(架空改名,如「通行宝钞」);钱庄银号、银钱比价波动可入戏。
- 开海:市舶司、民间海商(架空港名)、海禁与开海之争 = 朝堂长期议题;回程货胡椒苏木番银。
- 税制:赋役归并折银(仿一条鞭,架空名如「归并折色」)、清丈田亩(「清丈归亩」)、火耗、盐引开中、茶马互市。
- 商帮与产业:盐商 / 海商 / 南北商帮(架空名);江南织造、官窑(架空窑名)、皇店皇庄、勋贵庄田兼并。
- 经济议题入戏:税使扰民、丝价银价波动、漕运河工、开海派与禁海派的廷争 —— 都是合法冲突源。

## 五、文化风貌

- 心学书院讲会、士人结社(架空社名)、八股时文、书坊刊刻话本、昆腔戏曲、江南园林、藏书楼。

## 六、称谓(全篇统一,新增先入映射表)

- 阁部:阁老 / 元辅 / 部堂 / 堂翁;科道:宪台 / 台谏;宦官:公公 / 厂公 / 督主 / 内相,自称内侍 / 奴婢。
- 官员自称:臣(对上)/ 下官 / 学生 / 晚生;同寅称 兄台 / 世兄;门生称 座师 / 房师。
- 家宅:老爷 / 太太 / 夫人 / 姑娘 / 哥儿 / 姨娘;仆从:管家 / 长随 / 门子 / 嬷嬷 / 丫鬟;商贾:东家 / 朝奉 / 掌柜。

## 七、名物

- 货币:白银 / 纹银 / 足色 / 铜钱 / 宝钞(架空名);缎匹潞绸、官窑瓷器(架空名)、苏松棉布、漕船海船福船。
- 度量衡:里 / 丈 / 尺 / 亩 / 贯 / 两 / 钱 / 石;时间:时辰 / 更 / 旬 / 朔望 / 年号纪年。

## 八、诗词韵文

- 必备:回目对仗、回末「正是」两句;常备:回前诗、回中诗词 1–3 处(讲会赋诗、宴集联句、灯谜酒令)。
- 五七言绝律为主,词牌选常见(西江月 / 临江仙 / 鹧鸪天);诗贴合情境禁堆砌;判词式预叙用于关键人物。

## 九、语言禁忌

- 现代词零容忍:公司 / 电话 / 心理 / 效率 / 秒 / 公里等;遇到先查映射总表,表外先补表。
- **清制及以后词汇也算穿帮**:军机处、奏折、巡抚衙门挂牌格式等不可用;用「题本 / 奏本 / 揭帖」等明制文书。
- 欧化长句拆短;文白相间红楼梦语感,不作全文文言。

## 十、与原稿的边界

- 情节走向、章节边界、伏笔回收位置不变;每回篇幅 80%–120%。
- 连续 12 字雷同禁(公共章回套语豁免);人物姓氏全部古雅化(名 + 表字入人物表)。
- 查重命中若为公共套语,汇报中标注豁免;其余必须改写。
