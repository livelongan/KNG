# 文言传奇指南(唐传奇式 · 架空唐兴)

## 一、传奇文体框架

- 每章一篇独立传奇文,**浅近文言**(今人可读的唐传奇语感,非先秦古文)。
- 起笔:传记式三笔勾出 ——「某某者,某州某县人也。少倜傥,有奇节。」(姓名籍贯 + 身份 + 性格)。
- 篇名:取该章主要人物或事件,《X传》《X记》《X行》《X别传》,一律取自篇目对照表。
- 首行:`第 N 章 〈篇名〉`(保留序号便于与原稿对照)。
- 篇末**论赞必备**:「野史氏曰:……」三五句,评人物得失、寄讽喻(仿《南柯太守传》收束)。
- 篇幅:原章的 60%–100%(文言信息密度高);单章 > 2 万字按场景分段重写后拼接。

## 二、叙事笔法

- 简雅:删形容词堆砌,一字一句有用;多用四字节奏,骈散相间。
- 奇变:传奇之魂 —— 侠客夜访、异人预言、梦境幻化、无端而至的转折;原稿的巧合与奇幻元素保留并前置强化。
- 对话:文言语感但可稍俗白,人物语气有别;关键对话直录。
- 诗:不强制;进士行卷诗、宴集联句、题壁诗,重要处一两首;原稿金句可化为诗句。
- 白描:服色、鞍马、器物点出身位(紫绯袍、鱼袋、轩车);不写大段心理独白。

## 三、架空唐制(政治骨架)

- **架空红线**:年号自拟(全书一致);今上不书名;不出现真实历史人物(可虚写「汾阳王式勋臣」「邺侯式谋臣」的影子,不给真名);两京都城与州县地名自拟雅名。
- 中枢:中书门下政事堂,同中书门下平章事(宰相,或三五员);中书省(中书舍人)、门下省(给事中封驳);尚书省六部(郎中 / 员外郎)。
- 使职:盐铁转运使掌财赋、度支;翰林学士掌内制,号「内相」;宦官:内侍省、枢密使(典兵权限按架空设定)。
- 藩镇:节度使 / 观察使拥兵自重(自拟藩镇名);朝廷对藩镇姑息或讨伐 = 主线议题。
- 监察:御史台(侍御史 / 监察御史);谏官:左右拾遗、补阙。
- 朋党:进士党(科第出身)与门荫党(世族子弟)相争(自拟党名)。
- 地方:州(刺史 / 使君)— 县(县令 / 明府,县丞 / 主簿);禁军(自拟名,如神策式)。

## 四、中兴经济(经济骨架)

- 赋税:两税新法(架空名,如「两税均输」):户无主客以见居为簿,人无丁中以贫富为差,夏秋两征;「钱重物轻」的折价之争可入戏。
- 财赋:盐铁转运使掌盐铁茶税;江淮漕运(自拟河渠名);常平仓平抑。
- 货币:**铜钱与绢帛并行,白银不是日常货币**(「银两」是后世穿帮);大额以贯、匹计;**飞钱(便换)** = 汇兑,商贾官僚通用(可自拟名如「通飞券」)。
- 商业:坊市制度,两京东西市,击鼓开市、昏钟闭市、宵禁犯夜;胡商邸店(自拟胡商名);互市监掌边贸。
- 驿传:三十里一驿,乘驿马持符券;过所(通行证)关卡查验可入戏。

## 五、文化风貌

- 进士科以诗赋取士:行卷、纳卷;放榜后曲江宴(架空名)、雁塔题名(架空塔名)、探花使。
- 士人交游:干谒权门、投书献赋;胡乐胡舞、佛寺道观、剑侠与方士出入豪门。

## 六、称谓(全篇统一,新增先入映射表)

- 官场:使君(刺史)/ 明府(县令)/ 相公(宰相)/ 侍御 / 员外;宦官:中人 / 内侍;自称:仆 / 某 / 愚 / 小生。
- 士人互称:足下 / 仁兄;及第者称「前进士」。
- 家宅:阿郎(父)/ 娘子(已婚)/ 小娘子(未婚)/ 郎君;婢:青衣;仆:家童 / 苍头。
- **禁忌称谓**:大人(官称,后世用法)/ 老爷 / 太太 / 小姐 / 少爷(皆后世,用郎君 / 娘子替代)。

## 七、名物

- 货币:铜钱(架空通宝)/ 绢帛(匹);**禁「银两」作日常货币**。
- 符信:鱼符、告身(委任状)、过所(通行证)、驿券。
- 服色:三品以上紫、五品以上绯(仿唐品色,架空同制);器物:越瓯青瓷、鞍马、陌刀横刀、胡琴琵琶。
- 酒食:烧尾宴式宴席、葡萄酒、胡饼;煎茶渐兴。

## 八、语言禁忌

- 现代词零容忍:先查映射总表,表外先补表。
- **后世制度词穿帮**:银两 / 银两计价、大人(官称)、老爷、太太、小姐、少爷、内阁、巡抚、衙门(用官府 / 公门)、宝钞、军机处、奏折 —— 一律不可用。
- 不用白话长句与「的地得」现代结构;对偶紧句优先;全文文言,不以白话行文。

## 九、与原稿的边界

- 情节走向、章节边界、伏笔回收位置不变;每篇篇幅 60%–100%(文言压缩)。
- 连续 12 字雷同禁;人物姓名全部古雅化(名 + 字 / 行第入人物表)。
- 每篇结构自查:起笔传记式?篇末论赞?篇名与篇目表一致?无章回套语混入?
