# 文言传奇移植重写 novel-tang

目标:把原稿小说重写成**唐传奇式文言短篇** —— 每章一篇独立传奇文,世界观移植到**架空唐朝中兴之世**(两税盐铁、藩镇宦官、进士行卷)。

**使用前提:仅用于用户拥有版权或已获授权的原稿。**

## 0. 解析输入

- 同 novel-rewrite:一个或多个原稿路径 + 改写需求描述(可为文件路径,可附文风样本)。
- 缺需求描述必须先问,重点问四件事:
  1. **移植深度**:只换世界观外壳,还是人物姓名、书名一并古雅化(默认:全部古雅化);
  2. **中兴格局侧重**:藩镇之争 / 财赋盐铁 / 进士朋党,用户可指定主线议题;
  3. 原稿若为第一人称,确认改为第三人称传主叙述(唐传奇为传记体,重大转换,默认执行);
  4. 书名:保留或自拟集名(如《云京异闻录》)。
- 输出目录:原稿 `xxx/` → 同级 `xxx-copy/`;`summary.md` 生成在原稿目录。

## 1. 扫描章节(确定性脚本)

```
node .cline/skills/novel-tang/scripts/list-chapters.mjs <目录或文件...>
node .cline/skills/novel-tang/scripts/list-chapters.mjs <原稿目录> <副本目录>   # 对比覆盖
```

- 自然排序、忽略 `summary.md` 与进度文件、输出 `chars` 字数;对比模式查 `missingInCopy`。
- 章节名是中文数字时排序不可靠 → 先把顺序列给用户确认;开工前确认文件数、总字数、输出目录。

## 2. 通读并生成 summary.md(核心:移植映射 + 中兴格局)

- 分批读章(每批 ≤ 6 万字符),边读边记要点;用 [tang-summary-template.md](docs/tang-summary-template.md) 生成 `[原稿目录]/summary.md`,必须包含:
  1. **改写要求**(用户原话)与改写方案(第三人称传记体、浅近文言,显式声明人称转换);
  2. **移植映射总表**(全篇唯一权威对照):官制与机构(含藩镇宦官)/ 经济与财赋(两税、盐铁、飞钱、绢帛)/ 职业与身份 / 地名与府邸 / 名物与器物 / 称谓 / 年号纪年 —— **表外元素先补表后行文**;
  3. **中兴格局设定**:自拟年号、宰执与藩镇与宦官的三角关系、朋党(进士党 vs 门荫党,自拟党名)、财赋大事(盐铁/漕运/两税),作为背景板;
  4. **人物表**:原名 → 古雅姓名 + 字/行第(如张三郎),身份按映射,改名对照;
  5. **篇目对照表**:每章一行,原章名 → 篇名《XX传 / 记 / 行》(取该章主要人物或事件,重写时不自拟);
  6. 分章梗概(剧情要点、必须保留的情节点、出场人物、篇末论赞要点、穿插诗)。
- 超长小说分卷更新 summary;断点续跑且 summary 已存在时不要重建,只核对与补齐。

## 3. 逐篇重写

- 文件名与原稿一致;**章内首行改为 `第 N 章 〈篇名〉`**(篇名取自篇目对照表)。
- 文体硬规则见 [tang-style-guide.md](docs/tang-style-guide.md),核心:
  - 浅近文言传记体:起笔「某某者,某州人也」三笔勾出身;篇末**论赞必备**(`野史氏曰:……`,评得失寄讽喻);
  - **章回体元素一律不用**:无回目对仗、无「且听下回分解」、无「看官」说书套语(那是后世形式);
  - 简雅叙事,四字节奏、骈散相间;奇变(侠客、异人、梦境、预兆)是传奇之魂,保留并强化原稿的巧合与奇幻元素;
  - 诗不强制:进士行卷、宴集联句、题壁诗,重要处一两首;
  - **现代词与后世制度词零容忍**:银子/银两(唐日常货币是铜钱与绢帛)、大人、老爷、小姐、内阁、巡抚、衙门、宝钞等一律穿帮,先查映射表,表外补表;
  - 情节走向、章节边界、伏笔回收不变;**篇幅为目标章的 60%–100%**(文言信息密度高,允许显著压缩);人名官署全篇一致。
- 每篇写完立即查重:
  `node .cline/skills/novel-tang/scripts/check-similarity.mjs <原章文件> <副本篇文件>`
  `violationCount > 0` 改到 0(唐传奇无公共套语,命中一律改写)。
- **样章门槛:第 1 篇完成必须暂停**,展示篇名 + 全文(或开头 500 字 + 论赞),请用户确认文言深浅与传奇味;确认后再继续(用户明确要求"直接跑完"时跳过)。
- 每写完一篇立即更新进度文件。

## 4. 进度与断点续跑

- 进度文件:`[原稿目录]/.novel-tang-progress.md`,复选框逐篇勾选。
- 中断重跑:先读 summary.md 与进度文件,从首个未完成篇继续;全部完成后询问是否删除进度文件。

## 5. 校验与汇报

- 对比模式脚本:`missingInCopy` 为空、`extraInCopy` 为空;`totalChars` 偏差应在 -40% ~ 0 之间(文言压缩,可与用户约定具体区间)。
- **文体与专名专项(本技能特有)**:
  - 逐篇检查:首行篇名与篇目对照表一致、篇末有论赞(`曰:`收束)、起笔为传记式;
  - 反向搜索映射表中"原稿元素"字样在副本的残留(漏映射必须处理);
  - 搜索原稿主要人名残留;反向搜索**后世制度词**(银两、大人、老爷、小姐、内阁、巡抚、军机处、奏折)残留。
- 汇报:篇数、字数对比(注意文言压缩)、查重结果、映射表条目数、中兴格局要点;建议 git commit。
