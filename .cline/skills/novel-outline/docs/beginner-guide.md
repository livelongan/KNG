# 小白写大纲入门(novel-outline 方法论)

向用户讲解时按本文件组织语言;产出大纲文档时把相关概念写进「📖 教学注释」。

## 一、大纲是什么,为什么必写

大纲 = 写作前的**施工图**。三个作用:

1. **锚主线**——防写偏。写着写着爱上支线角色,是大纲不在的最典型症状。
2. **控节奏**——防灌水。每章有冲突、有钩子,读者才会一直翻。
3. **管伏笔**——防烂尾。"只埋不收"是读者差评重灾区。

小白最常见的死法不是"写不好",而是"写到 5 万字不知道下一章写什么"。大纲就是那时候救命的。

## 二、五步法(从灵感到大纲)

1. **定靶**:一句话简介 ≤25 字 = 谁 + 想要什么 + 最大障碍。写不出来 = 核心创意没长好,别急着写正文。
2. **搭骨**:三幕结构(建置 25% / 对抗 50% / 解决 25%),全书中部必须有一次"真相或关系反转"(中点)。
3. **造人**:每个重要人物四件套——**欲望**(想要什么)、**恐惧**(怕失去什么)、**秘密**(藏什么)、**弧线**(从头到尾变了吗)。反派不是"坏",是"欲望与主角相撞"。
4. **排章**:每章一行表——一句话梗概、核心冲突(谁要什么、被谁挡)、爽点(读者爽在哪)、章末钩子(让人点开下一章的理由)。
5. **埋线**:伏笔编号管理(F01…),埋的时候就想好在哪收。

## 三、三幕结构速查

| 幕 | 占比 | 任务 | 常见错误 |
| --- | --- | --- | --- |
| 第一幕 建置 | 约 25% | 亮危机、立主角欲望、给本事、卷入漩涡 | 开局流水账、铺垫过长 |
| 第二幕 对抗 | 约 50% | 升级、结盟与反扑、中点反转 | 中段灌水、事件无因果 |
| 第三幕 解决 | 约 25% | 摊牌、决战、付出代价、回收伏笔 | 反派降智、结局靠巧合 |

## 四、言情专用:感情线八拍

初遇即对手 → 被迫并肩 → 心动不自知 → 揭穿/信任崩塌 → 契约靠近 → 吃醋确认 → 误会爆发 → 双向奔赴。

要点:**每一拍都要搭在主线大事件上**,不要单独"为甜而甜"。心动要有事件托底,误会要有利害关系。

## 五、十个新手坑(= 自检十问的来源)

1. 开局流水账(出生写到出事)→ 危机前置,第 1 章就出事。
2. 金手指过大 → 能力必须付代价(露头即险、用一次耗一分)。
3. 反派降智 → 反派每次失手要有合理内因,且反扑一次比一次狠。
4. 伏笔只埋不收 → 上伏笔表,编号管理。
5. 感情线靠巧合 → 每次心动有事件托底。
6. 章末无钩子 → 每章最后一行"让人想点下一章"。
7. 设定堆砌 → 设定跟着剧情出,不开篇写说明书。
8. 配角抢戏 → 配角为主角欲望服务,戏份超标就砍。
9. 视角漂移 → 章内不切视角。
10. 中段灌水 → 事件之间必须"因为 A 所以 B",不是"然后 A 然后 B"。

## 六、大纲怎么变成日更

逐章大纲(一行)→ 当天细纲(该章 5-8 个场景节拍)→ 正文。**每天只细化当天要写的那一行**,不要一次性把全书细纲写完——会被细纲耗死。
