# 改写文风指南(洗稿质量标准)

## 硬性规则

1. 禁止出现与原稿**连续 12 字以上相同**的句子(人名、必需的歌谣/信件引用除外)。
2. 以 summary.md 的分章梗概为骨架**重讲故事**,不做逐句同义替换。
3. 每章篇幅为目标章的 80%–120%。
4. 剧情走向、章节边界、伏笔与回收位置不得变动(除非改写要求明确允许)。
5. 人名/地名/称谓全篇一致,严格执行人物表与改名对照;写完一章后自查旧名残留。

## 句式重组手法(组合使用,避免机械替换)

- 叙述顺序重排:倒叙开场、场景切换点前移或后移、因果呈现顺序调换
- 视角段落化:全知叙述改为人物受限视角(或按改写要求反向操作)
- 对话转换:直接引语 ⇄ 间接引语;合并或拆分对话轮次;调整说话人位置
- 描写置换:弃用原比喻,改用五感(视/听/嗅/触/温度)细节重写
- 段落重组:合并碎段、拆分长段、调整详略(新场景详写,过渡略写)

## 去 AI 腔

- 禁用:值得一提的是、总而言之、综上所述、随着故事的推进、不难发现、众所周知
- 少用(每章各 ≤ 3 次):不禁、缓缓、微微、突然、瞬间;"眼中闪过一丝 X"
- 多用:具体动作与物象代替情绪概括;对话短促口语化、贴合人物口癖
- 每章开头 300 字内进入具体场景或冲突;章尾留钩子(若原稿有此习惯)

## 一致性

- 说话方式与人物表的口癖对齐
- 数字、时间、称谓与 summary 时间线对齐,前后章衔接自然
- 专有名词、门派/组织名、技能名等与原稿保持一致或按对照表替换,全篇统一

## 流程注意

- 长章(> 2 万字)按场景分段重写后拼接,段与段之间重写过渡句
- 输出格式随源文件:`.md` 保留标题层级与分隔线;`.txt` 纯文本不带 markdown 标记
- 每完成一章立即勾选进度文件;不要攒批
