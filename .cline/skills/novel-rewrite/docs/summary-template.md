# summary.md 模板

生成 `[原稿目录]/summary.md` 时使用以下结构(按小说实际情况增减条目,小节顺序保持):

```markdown
# 《书名》改写总纲

> 原稿目录:<路径> · 章节数:N · 总字数:约 X 万字 · 生成日期:YYYY-MM-DD

## 一、改写要求(用户原话)

<逐字粘贴用户的改写需求描述,不做转述>

## 二、改写方案

- 叙事视角:<第一人称/第三人称限知/全知……>
- 文风基调:<冷峻/轻快/古雅……,附 2–3 条可执行的文风示例句>
- 时代/世界观调整:<不变/如何改>
- 人物调整:<性格弧线调整;改名对照见人物表>
- 情节调整:<必须保留什么 / 允许修改什么 / 删除什么 / 新增什么>
- 篇幅目标:<如:与原稿持平(80%–120%)>

## 三、人物表

| 姓名(原稿) | 姓名(改写后) | 身份 | 性格与口癖 | 关键关系 |
| --- | --- | --- | --- | --- |
|  |  |  |  |  |

## 四、世界观与时间线

- 设定要点:
- 主线:
- 主要伏笔(伏笔内容 → 埋设章 → 回收章):

## 五、分章梗概

### 第 1 章《章名》(原稿文件:xxx.md,约 x 千字)
- 剧情要点:
- 必须保留的情节点:
- 出场人物:
- 章尾钩子:

(逐章继续,直到最后一章)
```
