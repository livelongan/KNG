# 《折金枝》主线大纲(明暗双线)

> 📖 **教学注释**:双线不是主线+支线——明线给爽,暗线给"回头重看一遍"的回味。每卷写清"起点状态 → 终点状态",卷末人物和局势必须真的变了;中点是全书腰眼,暗线此段必须揭一层。

## 明线事件链

> 📖 教学注释:必须"因为 A 所以 B",不能"然后 A 然后 B"。新情节接不上链子的,砍。

圣旨赐婚(曹党借赐婚安"钉子"盯死沈慎之女)→ 替嫁(族叔甩包袱,女主将计就计求生)→ 新婚互探(互相识破装弱/藏拙)→ 漕帮刺杀(奉命"确认沈慎之女死活",反暴露男主身手与案情存在)→ 各取所需结盟共查 → 女主拆三层账,查出"金枝"与月钱名册 → 玉佩暗格开(F01),账册原本与血书现世 → 缺页追索,笔迹比对:两案出自同一支笔(中点)→ 曹党反扑:栽赃谋逆、借及笄礼拉拢谢家 → 男主借伤装死设局(F02)→ 寿宴孤身献证(F09)→ 女二倒戈(F03)、祖母交底账(F15)→ 收网曹党与长公主 → 宫变之夜,账退千军(F04/F08)→ 三司会审背账、追银追册 → 沉冤昭雪 → 辞权交印 → 真名再嫁。

## 暗线事件链

五年前:闻人洵设计漕银案——夺谢玉章主审权、借刀灭口、拉曹严做白手套、扶长公主做旗帜,银入私账养三千漕丁、开两炉私钱 → 新帝少年装弱,默许沈慎"戴罪查案"、重设察事厅反钓 → 祖母当年为保门楣泄了儿子的查案进度,事后以赎罪之心监视漕帮账房(F15) → 沈慎流放不废查,以针脚暗码与女儿隔空并肩五年(F13) → 闻人洵布"靖难":私兵、私钱、傀儡幼王萧元亨、拉拢谢家(明漪婚谋,F10) → 男主女主两线合流,逼棋手提前动手 → 寿宴收网只网住旗帜,棋手同夜入局 → 宫变之谋败于账(漕丁知月钱出自朝廷,哗变倒戈) → 师徒摊牌,双佩合契开遗诏匣(F01/F16) → 棋子自断棋路(顾聿城揭师、曹奉反咬)、旗帜交出行踪册 → 装弱者亲政,棋手入狱。

## 女主成长线(弧线落点)

被安排(替嫁、顶名、连收养都是别人落的子,1-7)→ 识局(发现自己是棋子,8-11)→ 入局(主动结盟交底,11-14)→ 破局(契约重生、以账立身,15-32)→ 掀桌(孤身入局、账退千军,33-49)→ 执棋(堂上背账、证据链合龙,49-56)→ 归位(真名再嫁、自己接印,57-60)。

> 📖 教学注释:对照 01 人物小传"弧线一句话"逐段检查。她最大的反转不是查出真相,而是把"所有人为她定的局"掀了,换她自己的人生——这就是暗线给她最好的礼物。

## 高潮与结局

- 明线高潮:第 47-48 章寿宴收网(曹党+长公主)。
- 暗线高潮(全书顶点):第 49-52 章宫变之夜→账退千军→师徒摊牌→双佩开匣。
- 情感高潮:第 41-44 章"发丧"误会;第 60 章真名再嫁。
- 结局:平反、辞权、重办的婚礼;尾声:夫妻南下勘河,漕运新政施行;彩蛋:《漕河图》屏风挂进新政衙门(F11)。
